Platzhalter is a real-time, multi-user seating plan editor built for weddings, conferences, and corporate events. Design your floor plan on a canvas, organize guests into groups, drag them to seats, and export the final plan as a PDF.



### Setup

```bash
reopen in devcontainer

Zweites Terminal öffnen und 
cd frontend
bun run dev

im anderen Terminal 
cd backend
air

Frontend erreichbar unter http://localhost:3000
Email Dummy errichbar unter http://localhost:8030
```

The app is now running at **http://localhost:3000**. An admin user is auto-created from the `ADMIN_EMAIL` / `ADMIN_PASSWORD` env vars on first boot.

## Architecture

```
┌──────────────┐     REST/JSON      ┌──────────────┐     SQL      ┌────────────┐
│   Next.js    │ ←── Bearer JWT ──→ │   Go Fiber   │ ←── pgx ──→ │ PostgreSQL │
│  App Router  │                    │   /api/v1/*  │              │            │
└──────────────┘                    └──────────────┘              └────────────┘
       ↑                                   ↑
  BetterAuth                          JWT Validation
  (Session + JWT)                     (Middleware)
```

- **Frontend** — Pure UI layer. No business logic in API routes. Proxies `/api/v1/*` to the Go backend via Next.js rewrites.
- **Backend** — Stateless REST API handling all business logic, authorization, and database access.
- **Database** — PostgreSQL with schema managed by golang-migrate. Queries generated by sqlc — no ORM.
- **Auth** — BetterAuth on the Next.js layer issues JWTs. Go Fiber validates tokens via middleware. HttpOnly cookies only.

## Development
### API Overview

All endpoints require JWT authentication via `Authorization: Bearer <token>`.

```
GET    /api/v1/events                    List events
POST   /api/v1/events                    Create event
GET    /api/v1/events/:id                Get event
PUT    /api/v1/events/:id                Update event
DELETE /api/v1/events/:id                Delete event

GET    /api/v1/events/:id/floorplan      Get floor plan
PUT    /api/v1/events/:id/floorplan      Update floor plan (optimistic locking)

GET    /api/v1/events/:eid/persons       List guests
POST   /api/v1/events/:eid/persons       Create guest
PUT    /api/v1/persons/:id               Update guest
PUT    /api/v1/persons/:id/seat          Assign seat
PUT    /api/v1/persons/:id/park          Unassign seat
DELETE /api/v1/persons/:id               Delete guest
POST   /api/v1/persons/swap              Swap two guests' seats
POST   /api/v1/persons/bulk-assign       Bulk seat assignment

GET    /api/v1/events/:eid/groups        List groups
POST   /api/v1/events/:eid/groups        Create group
PUT    /api/v1/groups/:id                Update group
DELETE /api/v1/groups/:id                Delete group
POST   /api/v1/groups/merge              Merge two groups

GET    /api/v1/events/:id/stream         SSE real-time updates
```
